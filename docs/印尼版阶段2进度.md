## 2. 开关

`packages/frontend/src/lib/market-features.ts`：

| 开关      | 当前值  | 挡住的能力                                                                  |
| --------- | ------- | --------------------------------------------------------------------------- |
| `payment` | `false` | 充值页、订单页、下单 mutation、支付回跳 restore、402 跳 `/profile/recharge` |
| `wishes`  | `false` | `/create`、`/create/wish`、`/api/wishes` 读写                               |
| `voice`   | `false` | 语音配置/会话查询、生成 mutation、自定义台词页、工具箱音色设置              |

钱包余额、签到、消费明细、邀请 **没有** 被这个开关关掉。

## 3. 对照计划验收表

| 入口 / 场景                         | 副本改动                                                                                                   | 本轮验证                                                                                                      |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 创作 Tab、`/create`、`/create/wish` | 仍保留第四 Tab；落到印尼语占位页；不调用 `/api/wishes`                                                     | 浏览器打开 `/create`：标题 _Kreasi_，没有「许愿池」按钮，底栏仍是四列                                         |

| 图片设置                            | 仍是占位，文案换成印尼语共享面板                                                                           | 代码路径已接                                                                                                  |

API 层兜底：

- `POST /api/payment/orders` 被前端 mutation 拦截
- `usePaymentPlansQuery` / `usePaymentOrderQuery` / `usePaymentOrdersInfiniteQuery` 的 `enabled` 为 false
- `useWishStatusQuery` 的 `enabled` 为 false；create/complete/exit 写入直接 return/throw
- `useVoiceConfigQuery` / `useSessionVoiceQuery` 的 `enabled` 为 false；patch/generate throw

## 6. 加回这些能力时怎么拆

1. `MARKET_FEATURES.payment / wishes / voice` 改 `true`
2. 占位页会自动把原实现渲染出来（各 page 里的 `*PageContent` / `*PageLive` 还在）
3. 402 会重新跳 `/profile/recharge`（`resolveRechargeHrefForInsufficientCredits` 的开启分支）
4. 支付回跳会重新 `replace` 到订单/等待页

不要从中文仓再 copy 一遍这些页。
